# Каталог товаров (ЛР №1)

Консольное приложение для управления каталогом книг и журналов. Данные хранятся в файле `catalog.json`.

## Требования

- JDK 21
- Maven (встроен в IntelliJ IDEA)

## Запуск

### Из IntelliJ IDEA

1. Откройте проект и дождитесь загрузки зависимостей Maven (при необходимости — кнопка **Reload** в окне Maven).
2. Откройте `src/main/java/org/example/CatalogApplication.java` и нажмите ▶ рядом с методом `main`.
3. Меню появится в окне **Run**.

### Из терминала

```bash
mvn package
java -jar target/lab1psp-1.0-SNAPSHOT.jar
```

## Файл каталога

- При запуске программа читает `catalog.json` из **рабочей папки** (в IDEA — корень проекта).
- Файла нет → создаётся пустой каталог.
- Файл повреждён → выводится сообщение об ошибке, каталог очищается.
- Сохранение происходит при выборе пункта **«5. Сохранить и выйти»**.
- Путь к файлу можно изменить в `src/main/resources/application.properties`:
  ```properties
  catalog.file-path=catalog.json
  ```

В корне проекта лежит пример `catalog.json` с 3 книгами и 2 журналами.

## Меню

```
===== Каталог товаров =====
1. Добавить книгу
2. Добавить журнал
3. Все товары
4. Удалить товар (по ID)
5. Сохранить и выйти
```

Введите номер пункта и нажмите Enter.

### 1. Добавить книгу

Программа по очереди запросит:

| Поле                | Формат                              |
|---------------------|-------------------------------------|
| Название            | текст                               |
| Цена                | число ≥ 0, например `499.90` или `499,90` |
| Автор               | текст                               |
| Количество страниц  | целое число > 0                     |

ID присваивается автоматически и выводится после добавления.

### 2. Добавить журнал

Аналогично книге, но вместо автора и страниц:

| Поле           | Формат          |
|----------------|-----------------|
| Издатель       | текст           |
| Номер выпуска  | целое число > 0 |

### 3. Все товары

Выводит список товаров:

```
[Книга]  ID: 1 | Название: Война и мир | Цена: 899.90 | Автор: Лев Толстой | Страниц: 1274
[Журнал] ID: 4 | Название: Наука и жизнь | Цена: 320.00 | Издатель: АНО Наука и жизнь | Выпуск №9
```

### 4. Удалить товар (по ID)

Введите ID товара (его видно в пункте 3). Если товара с таким ID нет, будет выведено сообщение об ошибке.

### 5. Сохранить и выйти

Сохраняет каталог в `catalog.json` и завершает работу. Если записать файл не удалось (например, нет прав или файл занят), программа сообщит об ошибке и спросит, выйти ли без сохранения (`y` / `n`).

## Ошибки ввода

Программа не завершается при неверном вводе — она выводит сообщение и просит ввести значение заново:

```
Цена: abc
Ошибка формата: ожидается число (например 199.99), введено "abc".
Цена: 499.90
```

- В числовые поля (цена, страницы, номер выпуска, ID) нельзя вводить буквы.
- В текстовые поля (название, автор, издатель) нельзя вводить только цифры или пустую строку.

> Изменения, сделанные в программе, попадают в файл только после пункта 5. Если закрыть программу кнопкой Stop в IDEA, изменения потеряются.
