# Лабораторная работа №1

Консольный каталог книг и журналов на Java 21 и Spring Boot. Можно добавить товар, посмотреть каталог и удалить товар по ID. Данные загружаются из `catalog.json` и сохраняются при выходе.

Для запуска нужны JDK 21 и Maven:

```bash
mvn package
java -jar target/lab1psp-1.0-SNAPSHOT.jar
```

В IntelliJ IDEA можно запустить `CatalogApplication`.
